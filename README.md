## Featured projects

### [E-Fuel](https://github.com/megharajpanchmaal19-glitch/e-fuel): online fuel booking system
Customers browse fuel types and stations and place delivery or pickup orders. Admins manage users, fuels, stations and bookings.
**Stack:** React, Vite, Tailwind CSS, Flask, SQLAlchemy, MySQL, Nginx, Docker Compose, Jenkins

### [Trace Room](https://github.com/megharajpanchmaal19-glitch/trace-room-preview): financial-network analysis demo
A browser UI for exploring cases, entities, transactions and evidence as a graph, using synthetic data only. It saves to a local Neo4j database through an API and falls back to a local preview mode when the API is offline.
**Stack:** JavaScript, FastAPI, Neo4j

### [SmartBot](https://github.com/megharajpanchmaal19-glitch/codealpha_smartbot): rule-based chatbot web app
A Django chatbot with keyword and intent matching, per-visitor conversation history stored in MySQL, and a responsive chat UI.
**Stack:** Python, Django, MySQL, HTML, CSS, JavaScript

### [Stock Portfolio Tracker](https://github.com/megharajpanchmaal19-glitch/codealpha_stockportfolio): simulated portfolio manager
Add, edit and remove holdings and see total investment, calculated on the server. It uses fixed sample prices, not live market data.
**Stack:** Python, Django, MySQL, HTML, CSS, JavaScript, GitHub Actions
